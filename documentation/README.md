# Follow the website: study guides

Start with [App startup, MVC, and the word guide](00-start-here.md). Then choose a topic below. There is one full walkthrough for each of the 20 examples.

Each guide includes the page GET, form fields, POST route, input checks, model calculation, returned View, sample input and answer, exact source lines, and an Express comparison. Read the numbered steps in order while opening the linked code.

Source links point to this workspace's full paths and line numbers so you can open them from Codex. If your editor does not support a link ending in `:25`, open the named file and use Go to Line (usually Ctrl+G), then enter 25. Source line references were checked against the saved code on 2026-11-05. Moving the project or editing its files may require updating those links.
